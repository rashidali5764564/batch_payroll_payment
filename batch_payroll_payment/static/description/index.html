Batch Payroll Payment

Pay multiple payroll payslips in one action

Overview

This module allows HR and Accounting users to pay multiple payroll payslips in one action using Odoo standard payment register wizard.

Key Features

  • Batch payment of multiple payslips
  • Uses standard Odoo payment flow
  • Validation of posted journal entries
  • Multi-company supported
